# Отчёт о проверке изменений

- TypeScript: `tsc --noEmit` — успешно.
- Автоматизированные изолированные тесты `node --test scripts/test-*.cjs`: **63 успешно, 0 ошибок**.
- Переводы: в каждой локали равное количество ключей; `npm run check:i18n` — успешно.
- Публичные правила Firestore и коллекции `bookings`, `orders`, `siteContent/main` сохранены.
- Изменено: двухэтапный админ-вход, CSS телефона, фон/акции, редактор изображений, инструкции и проверки.
- Production Vite bundle: **не подтверждён** в текущей Linux-среде. `tsc -b` проходит, но `vite build` блокируется отсутствием Linux-пакета `@rollup/rollup-linux-x64-gnu` (пользовательский архив содержал macOS node_modules). Выполните `npm ci && npm run verify` на Mac.
- Фактический вход Google/администратора, доставка писем, Firestore write/read, загрузка Cloudinary, iOS/Android браузеры и обновления между устройствами: **не тестировались против реального проекта**, для этого нужны включённые провайдеры, настройки и доступ клиента/владельца.
- Не создавалась новая база, не менялись опубликованные удалённые правила Firebase и Vercel.
