# EL BEM BEAUTY — React / Vite / Firebase

Полный исходный проект (не набор патчей). Сохранены предыдущие страницы, бронирование, магазин, клиентский кабинет, админ-панель, KG/RU/EN, музыку и акции. Основной стек: React, TypeScript, Vite, CSS, Firebase Auth + Firestore. Максимальная длительность онлайн-записи — 210 минут.

## Локальный запуск

1. Распакуйте ZIP; откройте папку `EL_BEM_BEAUTY` в VS Code.
2. Скопируйте `.env.example` в `.env.local` и заполните **те же данные Firebase**, что использует текущий проект (`el-bem-beauty`), а также `VITE_ADMIN_LOGIN_EMAIL` — email существующего служебного аккаунта с ролью `admin: true`.
3. Выполните:

```
npm ci
npm run verify
npm run dev
```

4. Откройте адрес Vite, проверьте личный кабинет и `/admin` в двух разных браузерах. Изменения Firestore Rules публикуйте только после сравнения с вашими текущими правилами. Для Google-входа один раз включите провайдер в Firebase Authentication.

## Что исправлено в этой версии

- Телефонная группа на регистрации, бронировании и в корзине теперь занимает всю ширину, поле номера не схлопывается старой CSS-сеткой.
- Личный кабинет всегда входит по личным данным. Админка требует два последовательных входа: личные данные, затем отдельный пароль служебного Firebase-аккаунта с правом `admin: true`.
- Убрана конфликтующая форма переноса email административной учётной записи.
- Выбор фото с устройства доступен в редакторах и галерее; опциональная прямая загрузка Cloudinary, либо локальный предпросмотр без публикации.
- Более насыщенный кремово-пудровый/винный фон и отдельное контрастное оформление блока акций в обеих темах.
- Сохранены существующие подписки Firebase, бронирования, заказы, музыка и управление акциями.

## Документация

- `OWNER_ACCESS_RU.md` — поэтапный вход и защита владельца;
- `MEDIA_SETUP_RU.md` — фотографии, локальное сохранение и Cloudinary;
- `FIREBASE_SETUP_RU.md` — настройки существующей базы;
- `RELEASE_QA_RU.md` — ограничения и проверка релиза.

Секреты, `.env.local`, `node_modules`, `dist` и резервные копии в архив не входят. **Сборка/тесты без доступа к реальной базе НЕ подтверждают работу Firebase на аккаунтах владельца**.
